# 人做准备，Agent部署验收｜短版口播

目标：只讲两部分的交接流程。详细技术步骤供Agent读取，不做逐命令长课。按项目现有SSH方式处理远程接入；不是QQ登录。

## 制作约束
- 1080×1920竖屏，小米MiMo冰糖配音，目标2–3分钟。
- 硬性上限180秒；按实际配音测量，超长精简内容，不强行加速。
- 本人负责必要准备与账号授权；正常部署、配置、诊断和验收交给有实际执行权限的Agent。
- 没有执行能力不冒充执行；新机兼容与下载阻塞按实际证据报告。
- 本轮仅制作视频和交接文档，不操作手机；旧长课保留参考，不作为当前发布版。

## 分镜与口播

### 001｜人准备，Agent来部署
责任：分工总览

用手机部署机器人，不需要你跟着敲几十分钟命令。把工作分成两部分：人完成准备和授权，Agent 接手部署、配置和检查。

画面：人：准备设备和访问授权；Agent：部署、配置、检查；详细命令放进执行文档
提示：视频讲交接流程，不讲逐条安装命令

### 002｜人：安装与手机权限
责任：人负责

人先从官方来源安装 Termux，准备好网络、空间和自己的测试账号，并处理手机弹出的必要权限。环境和机器人软件，不用你一个个手动安装。

画面：从官方来源安装Termux；准备稳定网络和可用空间；允许必要的后台运行
提示：已有部署先保留，不清空手机环境

### 003｜人：接通远程连接
责任：人负责

然后按准备文档开启 SSH，完成安全连接和授权，确认 Agent 真的能进入手机终端。只把文档发给普通聊天助手，并不会自动获得控制手机的能力。

画面：本项目按SSH连接手机；私下配置认证与访问授权；确认Agent确实能执行命令
提示：连接信息私下配置；不在视频里展示

### 004｜人：把执行文档交出去
责任：人负责

连接成功后，把详细部署文档和执行任务书交给 Agent，说明目标、已有环境和授权范围。密码、令牌与模型密钥放在私有配置里，不写进公开文档。

画面：说明想部署什么及已有状态；提供主教程、执行任务书和验收标准；不要在提示词里粘贴密钥
提示：到这里完成交接，不再逐条代Agent敲命令

### 006｜Agent：自动部署配置
责任：Agent负责

Agent 先检查环境并保护已有数据，再按文档自动安装、配置 AstrBot 和 NapCat，接通 OneBot 和指定模型。启动、恢复与正常排错，也由 Agent 自己完成。

画面：先预检并保护已有部署；自动安装、配置和接通模型；启动、恢复与排错由Agent执行
提示：失败自主诊断；外部阻塞如实报告

### 007｜必须本人时才叫你
责任：必要时交回给人

只有首次扫码、安全验证或新增授权时，才需要你回来确认。完成这一步，Agent 继续执行，不会把后面的技术工作再交给你。

画面：QQ首次扫码或安全验证；需要新权限或超出原定范围；其他正常技术步骤继续自动做
提示：SSH连接不是QQ授权，不能替代本人验证

### 008｜Agent：检查到真实结果
责任：Agent负责

最后，Agent 自己检查服务、QQ 登录、OneBot 连接，再验证模型调用和授权范围内的真实收发。能打开网页不算全部通过；失败就定位问题，没验证的项目明确标出来。

画面：服务健康 → QQ登录 → OneBot连接；模型调用与获准测试目标的真实收发；失败继续定位，不能只看网页能打开
提示：不群发，不把示意结果当实测证据

### 009｜交付一张验收回执
责任：Agent负责

检查结束，Agent 交付一张清楚的回执：哪些通过、哪些还没通过、以后怎么启动和恢复。全部目标有证据通过才叫完成；有外部限制，就说明还缺什么。

画面：哪些已通过，证据是什么；哪些未通过，还缺什么；以后如何启动、恢复和回退
提示：回执示意；本轮视频制作没有操作手机
