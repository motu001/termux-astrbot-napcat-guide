# 当前发布版：人做准备，Agent部署验收

本版实际时长 **2分33秒**，1080×1920竖屏，小米MiMo TTS「冰糖」配音，24条短语字幕。整片3680帧解码检查通过。

这版替代56分钟逐命令长课作为发布方案。只讲两件事：

1. **人需要做的部分**：安装Termux、处理手机必要权限，按本项目的SSH方式接通可信Agent并授权，把目标和执行文档交出去。账号首次扫码/安全确认仍由本人在需要时完成。
2. **Agent需要做的部分**：具备实际执行权限后，自主预检、部署、配置、排错和验收。正常步骤不再让人逐条复制命令；缺少权限或遇到必须本人操作的事情时才交回。

## 制作源码

`make_short.py`复用同仓库`video/tutorial_20261003/`中的已测试渲染和合成模块，不重复复制整套引擎。安装与配置方式见[共享引擎说明](../tutorial_20261003/README.md)。

```powershell
python make_short.py preflight
python make_short.py audio
python make_short.py video
python qa_short.py
```

只有`audio`会调用你自己配置的小米TTS账户；沿用冰糖声线。内容分为2部分8段，成片超过180秒则阻止合成，先精简口播而不强行加速。音频、视频和凭据不上传此仓库。

检查已覆盖8段配音及字幕源一致性、24种画面状态、180秒上限和3680帧整片解码。修复共享引擎工作目录早绑定导致的旧字幕引用，并经11项回归测试及最终8帧抽查确认。未做本轮手机部署或人工全片听审。
