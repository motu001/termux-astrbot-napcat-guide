# 人机分工｜3D动画视觉重制版

本轮针对“静态卡片粗糙、画面简单”的反馈重做视觉，**没有改变2分33秒的人机分工结构，也没有重新调用TTS**。

## 画面变化
- 本机GPU离屏渲染三维手机、金属人端标识、发光Agent核心、文档和部署模块。
- 相机与物体持续运动；文档沿轨迹交接，软件模块组合落位，检查阶段加入扫描表现。
- 对象姿态平滑衔接、屏幕内容交叉淡化、光扫转场；动态标题和短语字幕取代满屏静态条目。
- 近似PBR光照、环境反光、柔和阴影、1.5倍超采样和Bloom。场景是教学动画，不是实际手机界面或部署成功证据。
- 原小米MiMo配音不变，增加低音量的原创合成过渡声，不使用外部曲库。

## 检查与限制

1080×1920、30fps、4600帧、153.333秒。9项测试通过，八段均检测到不依赖字幕的三维画面变化，七处段落边界的姿态连续性通过；整片解码、音轨与最终8个画面抽查通过。复用旁白解码相关系数约0.99997，区别来自轻音效及AAC重编码。

这不是新的部署实测，也不是对任何手机兼容性的保证。没有操作手机、读取凭据或自动发布抖音。审美效果仍由使用者审片决定，不把技术测试当作用户认可。

## 重制

本地验证环境为Windows、支持OpenGL 3.3的NVIDIA显卡、带NVENC的FFmpeg，以及微软雅黑/Consolas字体。本目录不分发系统字体、音频或视频。

- 三维渲染：`render_motion.py`、`scene.frag`、`composite.frag`。
- 动态版式：`overlay.py`。
- 输入：优先读取相邻[人机分工短版工程](../handoff_short_20261003/README.md)的时间线和字幕；也附有已脱敏的本版固定时间元数据，便于不付费地检查静帧。
- 成片需要与时间线匹配的原配音。先准备短版配音，输出位置和名称沿用短版工程；不要拿任意音轨套用这个固定时间线。

```powershell
python -m pip install -r requirements.txt
python tests_overlay.py
python tests_motion.py
python render_motion.py frames
python render_motion.py preview
python render_motion.py full
python verify_final.py
```

默认输出到仓库根目录`06_成片/人机分工_3D动画版_20261003/`。`frames`不需要配音；`preview/full`缺少原配音时先停止，不偷偷调用TTS。生成媒体不随Git上传。
