# 手机部署 QQ 机器人：人做准备，Agent 部署与验收

> **零镜像新手教程（2026-10-03 更新；上游资料核对 2026-10-03）**：只用官方公开来源准备 Termux、PRoot 发行版镜像、AstrBot 和 NapCat，不需要机主的私有镜像或备份。每一步都有成功判据与失败停止点；尚未在全新设备逐步端到端复现，NapCat/QQ 的下载、登录和兼容性不可保证。无需 root；不是 Docker 一键部署。先读[完整教程](docs/从零安装与连接.md)和[安全说明](docs/安全与故障排查.md)。

```text
测试 QQ 号 → Linux QQ / NapCat ──OneBot v11 反向 WebSocket──> AstrBot → 回复
                    ↑                                      ↑
             Termux 内的用户态环境                    Ubuntu PRoot 用户态
                     Android ARM64 手机（两者共享手机网络）
```

## 当前主流程：人做准备，Agent接手

**不是让人学完整套部署命令，而是完成必要准备后，把执行交给具备终端/SSH能力的Agent。** 本项目按现有SSH连接方式说明远程交接；连接手机不等于已经完成QQ账号授权。

### 人需要做

1. 安装Termux，准备网络、空间和必要的Android权限。
2. 私下配置认证与连接，确认可信Agent实际能够访问手机终端；不要把密码或私钥粘贴进公开提示词。
3. 说明部署目标、已有环境和授权范围，把[准备与交接说明](docs/人做准备_Agent接手.md)及[Agent执行任务书](AI_协助部署_复制给AI.md)交给Agent。
4. 只有遇到首次扫码、安全验证或新增授权时，再由本人处理对应动作；完成后由Agent继续。

### Agent需要做

- 自主检查架构、空间、网络、版本和已有部署；保护原有数据。
- 按[详细执行手册](docs/从零安装与连接.md)完成环境、AstrBot、NapCat、连接、模型及启动配置，在授权范围内自行排错。
- 自己逐层验收服务、QQ登录、OneBot、模型调用、真实消息和已授权的恢复测试，再交付通过项、未验项、阻塞与维护说明。
- **不把正常步骤变成人逐条复制命令的陪跑课。** 无执行能力就说明缺少什么接入条件；外部阻塞或必须本人操作时明确交回，不假装已经完成。

## 适用范围和事实边界

- **已在一台 ARM64 安卓手机上观察到**：AstrBot、NapCat 和 ARM64 Linux QQ 在 Termux／PRoot 用户态运行；管理页可达，QQ 在线，OneBot 适配器出现连接；机主确认“可以回复”。实机采用私有备份提取后的隔离实例，不依赖本公开仓库。
- **2026-09-25 机主新增反馈**：在后续重启后可以对话。尚无可发布的本次逐消息服务端审计，也未核对这次是否免手动登录或回复的模型来源；不宣称无人值守 QQ 登录和 AI 生成已验收。
- **2026-09-25 单次真实重启检查**：开机脚本触发、核心管理服务与 SSH 恢复；最初 QQ 未自动登录，真实 OneBot 连接为 0。机主随后手动点击登录，状态接口显示 QQ 在线，AstrBot 真实适配器连接日志出现 1 次连接。**这不是 QQ 无人值守自动登录的证明**。仍未证明：全新手机从本文完整安装一次、该次重启后的逐消息服务侧审计、跨多次重启稳定恢复及可归因到 AI 模型生成的回复。因此本文不是“复制命令即可保证成功”的承诺。
- **2026-10-02 新增实测**：一次 NapCat/QQ 服务重启后，无需点击登录即自动上线，AstrBot 保持原进程，新增日志出现真实 OneBot 适配器连接。总测试耗时 136 秒；**未重启 Android 整机、未重测消息或 AI 回复**。详见[开机自启与 QQ 自动登录](docs/开机自启与QQ自动登录.md)。此项不替代上述历史整机重启记录。
- 本仓库**不提供** QQ、NapCat、AstrBot 的镜像/二进制/账号/模型密钥，也不含原机配置、备份或录屏。NapCat 是第三方 QQ 接入，可能受上游兼容性与账号风控影响；优先用自己的测试账号。
- PRoot 可以提供 Ubuntu 文件系统，但不是完整虚拟机或 Docker Engine。不要把 x86_64/AMD64 私有镜像当成可在 ARM64 手机上原样运行的服务；即使能解包，也不等于可以直接执行其中的架构相关程序。

## 开始之前

1. ARM64 安卓手机、有足够空间与内存、稳定 Wi-Fi，准备可供测试的 QQ 账号。
2. 按 [Termux 官方说明](https://github.com/termux/termux-app#installation)选择安装来源；不要混装签名不同的 Termux/插件。
3. 跟着 [从零安装与连接](docs/从零安装与连接.md)操作；**每一步失败先停下排错，不要继续堆命令**。
4. 网页只在手机本机或可信内网打开；推荐电脑通过 SSH 本地转发访问，**不做公网端口映射**。
