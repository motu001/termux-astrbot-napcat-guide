# 人做准备，Agent 接手

**不是逐命令长课。**人先准备设备与连接，再交付公开文档和有限授权；能执行的 Agent 自行部署。这里把“SS 登录”暂按 **SSH 远程终端登录**理解，不是 QQ 登录；若你指别的软件，先澄清。

## 1. 人先完成必要准备

- 使用自有 ARM64 安卓测试手机，准备充电、散热、足够空间及可信 Wi-Fi；Agent 所在电脑必须能到达手机。仅会聊天/浏览网页的 AI 不具备部署能力。
- 按[主教程第 1 关](从零安装与连接.md)中的官方来源安装 Termux，只做其中“1.1 安装应用”，打开并完成初始化即可；后面的Linux环境安装交给Agent。已有 Termux 不要为换来源卸载。按系统提示允许必要通知、后台运行；需开机恢复时再安装同签名来源的 Termux:Boot、打开一次并允许自启动。不授予无关通讯录、存储或 root 权限。

## 2. 开启 SSH，私下登录并验证

只在 **Termux 主终端**做这组连接准备；每条成功再继续，已有 SSH 配置先保留，不重置认证：

```sh
pkg update
pkg install openssh
```

本人私下配置认证：新装可运行 `passwd` 设置强密码，或按[Termux 官方 SSH 说明](https://wiki.termux.com/wiki/Remote_Access#SSH)配置公钥。密码仅在受信任的认证界面输入，私钥留在自己的设备，不发给 AI。未启动 SSH 时运行 `sshd`，已启动则跳过；随后查询身份和端口：

```sh
sshd
whoami
sshd -T | grep '^port '
```

从手机 Wi-Fi 详情取局域网 IP，用上面用户名和实际端口，在电脑终端连接（替换占位符）：

```text
ssh -p <实际端口> <Termux用户名>@<手机局域网IP>
```

首次连接先核对主机指纹；手机可用 `ssh-keygen -lf "$PREFIX/etc/ssh/ssh_host_ed25519_key.pub"` 查看对应公钥指纹。不一致先停，不关闭校验。连接失败先核对地址、端口、同网互通和认证，不做公网映射。

登录后运行 `whoami`、`uname -m` 确认目标。再让 Agent **通过它实际使用的执行工具**完成同样只读验证；只有你的终端连通还不算交接成功。认证通过受信任终端/密钥代理私下配置，任务书只写连接别名或会话标识。SSH 参数以本机为准；官方 SSH 网页本次访问受限，未完成在线复核。

## 3. 交接一次，按边界回交

把[AI 任务书](../AI_协助部署_复制给AI.md)填好，提供仓库或其列出的公开文档；说明目标、实例/目录范围、旧部署情况、测试对象与费用上限。不要附密码、Token、私钥、二维码或原始日志。

Agent 接手只读预检、安装配置、启动排错与分层回执；你无需逐条抄命令。遇本人认证或新增权限再回来处理：可等 Agent 安装完，在自己的面板完成 QQ 扫码、安全确认、模型账号与 Key 配置，再通知它继续。**一次 SSH 登录不能免除后续账号授权。**

完成标准是任务书中的服务、QQ、OneBot、模型、真实消息、恢复六层证据，不是“页面打开了”。下载/兼容阻塞如实保留，未能验证写“未验”；恢复测试中整机重启必须另行授权。
