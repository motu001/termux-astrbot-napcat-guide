# 视频录制/部署验收记录模板

> 复制到**自己的私有笔记**打勾；公开 issue 不填真实 IP、QQ 号、Token、二维码或 API Key。不要把本模板“待验收”改写成“已成功”。

- [ ] Termux 来源/签名可信，`uname -m` 与手机架构匹配。
- [ ] Ubuntu PRoot 可进入，`/etc/os-release` 正确；AstrBot 日志出现管理入口。
- [ ] NapCat 与手机架构对应的 Linux QQ 启动；**机主自行**完成 QQ 登录。
- [ ] 手机本机打开两个 WebUI；若用电脑，SSH 回环转发可达。不把 HTTP 管理页暴露公网。
- [ ] NapCat OneBot v11 WS 客户端连接 AstrBot；两端日志均能对应。
- [ ] 另一个测试 QQ 发消息、机主看到期望账号回复，记录时间和日志，但发布前脱敏。
- [ ] 需要宣称“AI 回复”时，确认该条回复确实由所选模型生成，而非固定规则/插件。
- [ ] 真实重启手机、在**无人手动启动服务**情况下验收自启、QQ 登录、OneBot 连接和回复。
- [ ] 最终视频逐帧检查：无二维码、聊天隐私、个人 IP、密码、Token、模型 Key、SSH 信息。
